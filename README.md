# CodeAlpha Social Media Platform

A full-stack social media platform built using:

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB Atlas
* JWT Authentication

## Features

* User Registration
* User Login
* JWT Authentication
* Create Posts
* View Posts Feed
* User Profile
* Logout Functionality

## Installation

1. Clone the repository

>>>bash
git clone <repository-url>


2. Install dependencies

>>>bash
npm install


3. Create a '.env' file

>>>env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key


4. Start the server

>>>bash
npm start
